# 后续工作（2026-11-05 用户确认）

用户在 2026-11-05 看过当天的汇报后确认了下面五项的方向，当天已完成前 3 项的实现与真机无人值守验证，详见 [11-05 蓝牙、跨开机保留与调光记录](../progress/2026-11-05-bluetooth-persistence-brightness.md)。本文保留用户要求与阶段结果，未完成事项集中在[待办目录](../backlog/README.md)。

## 1. 蓝牙

- 要求：支持蓝牙。
- 现状：已完成第 0～2 步（SE14 UART 驱动、WCN7850 固件下载、Skywalk 通道、`AnnibaleBT` IOService、`bluetool` 替身、`bluetoothd` 入系统盘、代答 `0x204a` 解除扩展广播锁定），`cycle.py` 默认开启 `bt=4`；控制中心与设置页蓝牙开关为开，BLE 扫描发现周边设备，见[蓝牙接入调研](../analysis/2026-11-02-bluetooth-bringup.md) §8。
- 3 Mbaud 已接入，配对、重连与音频验收见[外设待办 P5～P7](../backlog/platform.md)。

## 2. 跨开机保留数据

- 要求：设置、加入过的 Wi-Fi、装上的应用在重启后保留。
- 现状：已完成并在真机验证。`/private/var` 直接挂载在 UFS `darwin_var` 分区上，由内核块级持久化层（`ANNFS001`，双 32 MiB 乒乓元数据槽位与 4 KB 数据块直写）实时落盘，重启后直接恢复桌面布局、设置、已存 Wi-Fi 与已安装应用；切回 Android 运行核对用户数据正常，见[双系统分区与持久化部署手册](dual-boot-setup.md)与[根文件系统](../analysis/rootfs-strategy.md) §5。

## 3. 亮度

- 要求：亮度由系统里的亮度设置（控制中心与「设置」的滑块）控制，调的是面板背光，默认打开，不用开机参数。
- 现状：已完成并默认打开（`DCS_DEFAULT = 4`）。内核 `IOMFBBrightnessLevel` 将尼特数换算为该轮面板 DBV `5..0x1a5e`（6,750），经 DSI0 DMA FIFO 发送 DCS `0x51` 并用 `0x52` 回读确认，手势帧率无退化，见[屏幕亮度调节调研](../analysis/2026-11-02-brightness-control.md) §9。

## 4. GPU 性能（记录问题）

- 问题：120 Hz 屏上控制中心下拉约 90 帧／秒、翻页 90～100 帧／秒，长帧以 GPU 时间为主；一帧里 backboardd 提交 4 次以上时，七成以上是长帧（`rate8-ns1`），读数见 [11-05 记录](../progress/2026-11-05-defaults-and-charging.md) §3.1。
- 已有分析：[120 Hz 手势瓶颈](../analysis/2026-11-01-120hz-gesture-bottleneck.md)、[GPU 升频之后的长帧](../analysis/2026-11-02-120hz-after-gpu-clock.md)，候选做法列在[上游对照](../analysis/2026-11-05-upstream-lessons.md)。
- 后续性能对照与候选集中在[图形待办](../backlog/graphics.md)，按当前镜像重新测量。

## 5. 视频硬件解码（记录问题，调研方案）

- 问题：Safari 里 H.264 视频报 `err=3:Media failed to decode`，VP9 停在 `loadedmetadata`，读数见 [11-05 记录](../progress/2026-11-05-defaults-and-charging.md) §3.5。
- 早期分析发现两平面 YCbCr 合成与 VP9 解码器注册缺口，相关实现已落地；NV12／P010 色值与 VideoToolbox 会话的当前验收范围见[多媒体验证](../analysis/2026-11-11-multimedia-validation.md)。
- Iris 硬件首帧、冷启动播放与后续软件解码候选见[多媒体待办 M1／M4／M12](../backlog/multimedia.md)，设计与硬件资料保留在[视频解码分析](../analysis/2026-11-05-video-decode.md)。
