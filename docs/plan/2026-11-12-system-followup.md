# 系统可靠性与架构审查后续事项（2026-11-12）

## 1. 背景与范围

本轮接续[架构审查](../analysis/2026-11-08-architecture-review.md)，优先处理持久化、真实温度上报和应用管理。多媒体任务正在验证相机、Iris 硬解、音频、AIR 反射、YUV、背光与 loader 恢复；其实际完成范围见[多媒体验证结果](../analysis/2026-11-11-multimedia-validation.md)。

ir3 跨开机缓存已有命中实测，局部重绘已默认开启，慢帧栈采样也已有实现。局部重绘文档中的 `prior_copy` 根因说明与对应提交不一致，需核对归属；已有结果见[缓存实测](../analysis/2026-11-09-ir3-disk-cache.md)与[发热及管线优化](../progress/2026-11-09-thermal-and-pipeline-optimization.md)。

本轮先完成可独立验证的修复。持久化格式、系统温控服务和显示调度涉及更大契约，先复现缺口并确定边界，再决定实现范围。
