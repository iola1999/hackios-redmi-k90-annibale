## 2. 进行中与队列

- 架构审查（11-08，离线）：图形卡顿与颜色错误的结构性原因、外设未通项的路线判断、上游与同 SoC 项目更新及待用户决定事项，见[方案架构审查](../analysis/2026-11-08-architecture-review.md)；P0 为脏区重绘残留根因、材质着色器回归样本、缓存跨开机验证。
- 原版系统回归：完整 boot 已刷入并重启，UFS 切根、Cryptex、数据检查点和测试文件读回通过；早期透明图标随后恢复，大组件黑底及 Weather/Maps 内容请求继续排查，见[11-08 复核](../analysis/2026-11-08-issue-reassessment.md)。
- `/private/var` 直写验收：当前常用镜像正常重启后恢复检查点和测试文件，继续验证设置读回与异常复位恢复，见[根文件系统](../analysis/rootfs-strategy.md)。
- 历次反馈复核：32 条用户消息与文档中的图形、网络、音视频、启动、亮度、充电、应用安装及外设需求已整理；当前静态修复与真机验收边界见[11-08 复核](../analysis/2026-11-08-issue-reassessment.md)。
- 图形接口：真机 A/B/C 已通过越界 viewport、texture view 的 IOSurface 身份与写回检查，两个大组件仍黑底，继续检查远程组件实际绘制，见[11-08 复核 §3.2](../analysis/2026-11-08-issue-reassessment.md#32-清屏与附件)。
- 音视频：真机 AVPlayer 本地和 HTTP 输出均为 12 帧且摘要正确，NV12 单 plane 导入通过；DSP 扬声器与播放图已启动，会话激活成功后 AudioQueue 仍失败；format 500 片元与释放修复、首次 DSP 查询期限候选待上机，见[11-08 复核](../analysis/2026-11-08-issue-reassessment.md)。
- Weather/Maps：`geod` 已有 HTTP 200/304，Weather 仍无温度，Maps 停在定位服务提示框；具体请求与内容继续核对，见[11-08 复核 §3.3](../analysis/2026-11-08-issue-reassessment.md#33-音频与网络)。
- App Store：未完成。
- 蓝牙音频耳机连接与通话音频路由：SE14 UART 3 Mbaud 与配对基础已通，音频流端到端路由待进一步推进，见[蓝牙接入调研](../analysis/2026-11-02-bluetooth-bringup.md) §8。
- 原生调频与温控：分析并复刻 `CLPC`，核对与 `thermalmonitord` 的职责，待开始，见[路线图 §5.4](2026-10-26-roadmap.md#54-苹果原生策略分析与复刻clpc)。
- 120 Hz 后续细节调优与长帧治理：按[上游对照](../analysis/2026-11-05-upstream-lessons.md)推进整屏 pass 逐 draw 计时、Freedreno 局部更新附件保留与 Mesa ACD 调优。
- 渲染与内存遗留：局部重绘留下旧内容的原因待查，`package.py` 默认整帧重画；Spotlight 其余 52 个包的模型不在镜像里，ScreenContinuity 每轮 SIGTRAP 退出（[Spotlight 崩溃循环](../analysis/2026-10-31-spotlight-crash-loop.md)）。
- 代码行数：`userland/build.sh` 1153 行，保持在 AGENTS.md §2 的 1200 行上限以内；R6 全部 29 个新增与修改源码文件均控制在 1200 行以内；`tools/mesa/air/air_metal.c` 7012 行，存量超标文件大改时按职责拆分。
