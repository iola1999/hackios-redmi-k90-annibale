# v0.2.3 发布记录（2026-11-27）

## 1. 范围

本版继续使用 iOS 26.6.2（23G90，iPhone 17 `V57AP` 身份）与 XNU 12377，从三个仓库的日常分支发布：顶层 `43e2b98`、内核 `319d6f7`、用户态 `17929ae`（同步包含 `TrollStore` `582b283`）。相对 `v0.2.2` 的变化：

- 相机与照片：后摄对焦窗口外接框与 GT9764V `10.8 ms` 回位、照片发黑五处修复（RGB `2..18 -> 135..164`）、锐化散点、静态插值提速、闪光曝光回读、`F1` 静帧排队、`FocusNow` 元数据、`format 5` 修复与前摄 `30 fps` NEON/`180` 安装角，见[11-22 晚记录](2026-11-22-photo-motor-autolock.md)、[批 5 进展](2026-11-25-batch5-ane-fallback.md)。
- 音频与硬解：默认麦克风 DMIC0 录音（`TX macro dec1`、`1 kHz` 环回 `89.5 dB`）、HEVC Main 10 系统播放器 12 帧硬解、Iris 停机关闭 VPU 电源域与中途排空 `HFI_CMD_RESUME` 修复，见[11-24 麦克风录音验证](2026-11-24-mic-m8-resolved.md)、[多媒体验证 §121、§122](../analysis/2026-11-11-multimedia-validation.md#121-播放结束后的-vpu-停机11-24)。
- 图形与流畅度：「照片」图库网格（`cde3c65`）、「地图」建筑物（`b7c518b`）、翻页看门狗（`c80abfda`）、`MiniFramebuffer` 10 Hz 单核行哈希、`AnnibaleGPU` 锁外 `reap`（毛刺降至 `3.4 ms`）、`Keep` 池 512 扩容、Mesa `0029`/`0030`/`0031` 切片 B、`bl_arb`/`bl_dedup` 与 `adreno8_ifpc=1` 开关，见[批 9 收官与批 10 开局](2026-11-27-batch9-opening.md)。
- 网络、电源与存储：安装期 `assemble.py wifi-mac` 导入本机出厂地址（`703112cb`）、消除连续扫描与待机抬频（静置 `39.5–45.7 °C`）、Wi-Fi 开关图标修复、蓝牙 H4 重组、`batteryintelligenced` 启动修复、`input26` 自动锁定、APFS `va_write_gencount`/同步回传、UFS 槽缓冲与 ADSP `IPCRTR` `QMI SNS_CLIENT` 基础链路，见[待机发热对照 §8](../analysis/2026-11-22-idle-heat-vs-android.md#8-已做的修复与复测)、[批 9 收官 §5～§7](2026-11-27-batch9-opening.md#5-批-10-开局b5r30-与-b5r31-进展11-27-傍晚)。

用户侧变化：分区、系统盘和数据盘不变。因新增安装期 `wifi-mac` 导入，从 `v0.2.0`～`v0.2.2` 升级在 Android 下补采 `fw/wifi-mac.txt` 并重新执行 `assemble.py build` 刷入 `boot-ios.img`，按[开发指南 §11](../development.md#11-版本号)升修订号；`v0.1.2`～`v0.1.4` 先按 `v0.2.0` 的步骤迁移 APFS 数据盘并划分 `darwin_nvram`。

## 2. 构建与发布校验

发布包按 [Release 执行清单](../plan/release-checklist.md) 在新克隆 `../hackios-release-v0.2.3` 中构建，发布后已清理发布克隆下的 `ios26/` 提取目录。

- 内核：新克隆全量构建的 `xnu12377-local.bin`（`21,036,344` B，`52b4b873...`）与批 11 真机验证的 `xnu12377-flipwd21.bin`（`21,036,344` B，`d9b52ee0...`）长度及 `otool -l` 段布局完全一致（差异仅源于新克隆全量链接对象顺序及 `LC_UUID`）。
- loader 与引导镜像：`avbtool.py info_image` 验证 `boot-a-ios.img`（`100,663,296` B / 96 MiB）含 AVB v1.0 页脚（`Original image size: 24,535,040` B、`VBMeta offset: 24,535,040`、`512` B）。
- 用时：`ios` 18 s、`userland` 10 s、`mesa` 39 s、`package` 8 s、`kernel` 44 s、`loader` 3 s、`android` 0 s、`apfstool` 160 s，全部退出 0。

- 发布包：共 206 个条目，无隐私或 `wifi-mac` 敏感残留；`local files by kind {'plist': 558, 'copy': 13, 'skeleton': 1, 'firmware': 13, 'cache': 1}`、`property list edits carry 77498 bytes of values`；`manifest.json` 记录 `43e2b98fdd136d0bff5deebc8a5994067e94ea6a` / `319d6f780a99735d4626842f62fc33fe2a069efe` / `17929ae691bf9c71aff4734c1e6b63374663c880`。

## 4. 发版中发现的问题

- 内核补丁块头：`ba3aa586` 向 `hackios-xnu-kernel/xnu26/patches/30-iokit%conf%files.patch` 添加 `+iokit/Kernel/AnnibaleSMC.cpp` 后未同步更新第 5 行块头（`@@ -80,12 +80,25 @@` 实际有 26 行，应为 `+80,26`），导致新克隆 `xnu26/apply.sh` 报错退出。已于内核 `319d6f7`（顶层 `43e2b98`）修复，核对全仓 `84` 个补丁无其他坏块。
- 子模块远端提交：`TrollStore` 新提交 `582b283` 尚未推送至 `origin/k90-port`，导致外部新克隆 `git clone --recurse-submodules` 失败。已推送 `582b283` 至 `origin/k90-port`；两项检查均写入 [Release 执行清单 §9](../plan/release-checklist.md#9-历次发版遇到的问题)。
