# v0.1.3 发布记录（2026-11-13）

## 1. 范围

本版继续使用 iOS 26.6.2（23G90）与 XNU 12377，采用最近验证的输入归还内核、minmax AIR 和 heap Metal 组合。用户体验与验证边界见[多媒体验证 §70](../analysis/2026-11-11-multimedia-validation.md#70-11-13-人工体验与发布范围)。版本升级只需重新合成并刷入引导镜像，步骤见[体验说明 §12](../user-guide.md#12-升级)。

发布源码在三个仓库的 `codex/release-v0.1.3` 分支固定，日常分支继续保留后续实现。版本选择按冻结源码摘要逐文件核对，内核相机身份与 Iris 输入归还采用对应已验证修复。图形组合采用已有桌面图标可见的版本，当前相机 DMA 开发继续保留在日常工作区。

## 2. 当前限制

- 相机能打开并显示隐私指示灯，预览黑屏，真实 DMA 图像尚未取得。
- 270 帧离线 H.264 硬解完成，独立像素校验覆盖 269 帧；AVPlayer 连续播放仍只有三帧，后两帧像素与参考不同，关闭返回 EIO。
- Safari 正文空白与 sandbox token 编码退出仍需复核；天气和日历组件仍有内容缺失。
- 本版没有新增同条件性能对照，开机早期卡顿、实际声音输出与蓝牙音频继续验证。

## 3. 构建与发布校验

发布包从独立源码克隆重建，构建日志、源码选择清单与合成核对结果保存在 Git 忽略的 `out/release/` 和发布构建目录。最终源码提交、发布包与合成镜像的 SHA-256 由 Release 及包内 `manifest.json` 记录。

- 内核、用户态、loader、AIR 与根盘构建完成。AIR、Metal、shim 和主要注入库与冻结运行包逐字节一致。
- 根盘逐字节重建与 loader 封装校验通过；Linux 解包后的文件摘要全部匹配，完整合成的文件内容一致，zlib 版本差异导致压缩字节不同。
- 发布包的 140 个文件完成摘要与隐私检查，Iris 厂商固件通过本地输入提供。开发与发布克隆的 125 份 Markdown 检查通过。
- 本轮没有追加真机启动验证，设备体验沿用此前运行轮的结果。

## 4. 发布结果

[v0.1.3](https://github.com/iola1999/hackios-redmi-k90-annibale/releases/tag/v0.1.3) 已发布为最新版，附件为 `hackios-k90-v0.1.3.tar.gz` 与 `.sha256`。GitHub 附件摘要与本地文件一致，三个仓库的发布分支与标签均已推送。开发分支的已完成修复与进展记录已推送，相机 DMA 开发文件继续保留。

发布后的独立构建目录与镜像提取目录已清理，发布包、源码选择清单、验证 JSON 和日志保存在 `out/release/`；清理清单保存在本地 `out/cleanup-20261113/`。
