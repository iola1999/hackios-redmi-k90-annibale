# 阶段五进展：GPU 故障取证、Mesa 状态修复与蓝牙就绪门控（2026-11-19）

本轮围绕 `S21`（定位弹窗期间 GPU SMMU `0:0` 读取故障）与 `MISC-9`（蓝牙固件下载与设置页主线程状态）完成诊断能力合入、第一轮根因修复与内核宿主测试，并在完成关键验证后按当前优先级转向相机、GPS、蜂窝与性能专题。

## 1. S21：CP 故障现场转储、空指针防护与 `SP_*_PVT_MEM` 修复

- **内核故障定位增强**：在 [adreno8_gpu.c](../../hackios-xnu-kernel/xnu/files/bsd/dev/adreno8/adreno8_gpu.c)、[adreno8_context.c](../../hackios-xnu-kernel/xnu/files/bsd/dev/adreno8/adreno8_context.c) 与 [adreno8_bo.c](../../hackios-xnu-kernel/xnu/files/bsd/dev/adreno8/adreno8_bo.c) 补齐 `UCHE_CLIENT_PF` 客户号解析、`DDE_BR`／`DDE_BV`（pipe 6／7）全部 33 项 `SQE_STAT` 与 `SDS`/`MRB` 现场打印，并记录最近 16 条提交历史及最近 4096 次 BO 分配回收轨迹用于反查所属进程。
- **CP 现场定界**：[cp-state.py](../../tools/k90auto/cp-state.py) 与 [cp-words.py](../../tools/k90auto/cp-words.py) 适配工作区内本地 `a6xx.xml`／`adreno_pm4.xml` 路径并合并跨包树段。实机故障样本显示 `UCHE_CLIENT_PF = 0x81`（`BR_SP`）与 `DDE_BR`（pipe 6）停在 `draw 167`～`171` 区间，`draw 168` 写过非零 `SP_VS_PVT_MEM_BASE`，`draw 169` 在不需私有内存时将其写回 `0`。
- **Mesa 状态修复**：在 [0020-fd6-a8xx-state-bindless-and-bo-null.patch](../../hackios-xnu-userland/tools/mesa/rebase-26/0020-fd6-a8xx-state-bindless-and-bo-null.patch) 的 `fd6_program.cc` 中改为仅在 `pvtmem_bo` 非空时写入 `A6XX_SP_<STAGE>_PVT_MEM_*` 寄存器，同时为 `fd_bo_new()` 返回空指针路径（含 `upload_shader_variant` 与 `fd6_build_bindless_state`）补齐判空保护。
- **AIR 采样视图失效修复**：在 [air_metal_state.inc](../../hackios-xnu-userland/tools/mesa/air/air_metal_state.inc) 与 [air_metal_texels.inc](../../hackios-xnu-userland/tools/mesa/air/air_metal_texels.inc) 增加纹理写入后采样视图失效标记，防止纹理更新后跳过 `set_sampler_views`。
- **真机验证结果与暂停边界**：`s21-b3-r1` 轮（内核 `12377-s21bt8`，未开 `ANNIBALE_SYNC_DRAWS`）启动「地图」与 `CoreLocationVanillaWhenInUseAuthPromptPlugin` 弹窗后，背景地图完整出图，无故障连续提交 420 字大命令缓冲 `1,595` 次（由修复前 `138..180` 次提升至约 `130 s`，`Q 3394`～`Q 6585`），于 `Q 6585` 再次触发一次 `gpu SMMU fault 0x2 at 0:0, syndrome 0xe0002 fsynr1 0x3`（`pipe 6 SDS base 0x89597100 rem 123 init 155`）后由 `respin.py --stop` 正常退回 `xnuloader`。按工作优先级调整，后续地图长期稳定性暂缓，优先推进相机、GPS、蜂窝与性能实现。

## 2. MISC-9：蓝牙就绪门控与设置页主线程核查

- **传输就绪门控**：在 [annibale_bt_ios.c](../../hackios-xnu-kernel/xnu/files/bsd/dev/annibale/annibale_bt_ios.c)、[annibale_bt_hci.c](../../hackios-xnu-kernel/xnu/files/bsd/dev/annibale/annibale_bt_hci.c) 与 [annibale_bt_uart.c](../../hackios-xnu-kernel/xnu/files/bsd/dev/annibale/annibale_bt_uart.c) 改为原子读取 `bt_serving` 与 `bt_ended`，在 `bt_serving` 置位前拦截 `btsk_pre_connect`、`bt_kctl_send` 与 `bt_ios_put` 对 UART 的写入；在 `annibale_bt_start` 增加单次启动保护，并暴露只读 `kern.annibale.bt_piece` 与 `kern.annibale.bt_ended`。
- **运行态观测**：`s21-b3-r1` 轮蓝牙下载 40 片全部完成（`bt_ready=1`，耗时 `22,700 ms`）；`dump Preferences`（`pid 327`）采集到的 8 个线程里主线程（`tid 3442`）停在 `mach_msg2_trap`／`CFRunLoopRunSpecific` 空闲等待（`state 1 wait 0`），无死锁阻塞。驻留 `boot_a` 连续冷启动复测并入后续整合构建轮次统一验收。
