# v0.1.4 发布记录（2026-11-16）

## 1. 范围

本版继续使用 iOS 26.6.2（23G90）与 XNU 12377，从三个仓库的日常分支直接发布：顶层 `0f46d30`、内核 `072c6db6`、用户态 `4833b94`。相对 `v0.1.3` 的进展见 [README](../../README.md) 与[多专题研究记录](../analysis/2026-11-16-multi-topic-research.md)，主要是系统应用不再闪退、扬声器出声、AAC 与 HLS 播放、Iris 1080p 硬解、542 组件格式、TrollStore 安装入口和大安装包的 ramfs 克隆修复。

用户侧变化：相机寄存器表改为在本地从手机的传感器模块生成，合成时要多读两个文件并加 `--camera`，步骤见[体验说明 §5、§6](../user-guide.md#5-读取手机固件)。升级仍只需重新合成并刷入 `boot-ios.img`。

## 2. 当前限制

- 相机能打开，预览仍为黑屏。
- 天气、股票等联网组件只显示占位内容，用户确认暂不处理。
- 微博这类大安装包能装上，启动后被系统结束（S22）。
- 左右声道与上下扬声器的对应、音量调节、Safari 网页内视频没有验收；蜂窝网络、蓝牙配对与音频继续验证。

## 3. 构建与发布校验

发布包在新克隆里用 `tools/release/build-all.sh` 与 `build-release.py` 构建，日志与产物在 Git 忽略的发布克隆 `out/` 下。

- 内核：不含 ramfs 修复时从零构建的内核与真机轮使用的 `12377-iris1` 逐字节相同。加上 `072c6db6` 后，与 hackios-a7 真机验证的 `12377-clone1` 只差 LC_UUID：`clone1` 那次构建没有写入固定 UUID，其余字节相同。
- AIR 库：发布克隆与日常工作区从零准备 Mesa，两处库逐字节相同，包含此前没上过真机的 `rebase-26/0018`。`air0018-r2` 只换 AIR 库：主屏、负一屏组件、控制中心显示正常，没有新的崩溃，各类失败计数与基线 `share-r2` 相同。
- 根盘按生成方法重建后与 `package.py` 的输出逐字节相同；用发布包在 macOS 上执行 `assemble.py build --camera`，根盘与引导镜像均与发布记录逐字节相同。本版没有在 Linux 上合成。
- 测得的耗时：内核全量构建约 40 分钟，当时告警屏蔽尚未生效，日志 800 MB；Mesa 从零准备、建树、构建约 47 s；打包 8 s，loader 封装 2～3 s，`build-release.py` 21 s，`assemble.py` 7 s。

`air0018-r2` 的巡检里，原先点「设置」的坐标现在落在「钱包」上，点开后约 10 s 只显示变暗的主屏，`com.apple.Passbook-default` 场景已在前台。没有可对照的基线，是否与 0018 有关未确认。

## 4. 构建中发现的复现问题

这些问题都已在脚本里处理，维护方法见[开发指南 §10](../development.md#10-生成-release)。

- 新克隆缺少内核检出里指向用户态仓库的未跟踪链接，`package.py` 和 Mesa 准备步骤找不到文件。
- 日常 Mesa 构建树缺 `0018`，从仓库重建的库与设备上的不同；`build-air.py` 现在比对补丁摘要。
- `build-macos.sh` 的告警屏蔽参数不生效，全量构建日志约 23 万条告警。
- GPU 固件的文档位置写错；相机寄存器表、`AVCaptureSession.plist` 和 30 个 Angel 任务的缓存键没有正确的发布配方，前两项会被拒绝或整份带进发布包。
- 设备恢复时 `oem recovery` 两次中一次赶不上启动菜单窗口（ENG-23）。

## 5. 发布结果

[v0.1.4](https://github.com/iola1999/hackios-redmi-k90-annibale/releases/tag/v0.1.4) 已发布为最新版，附件为 `hackios-k90-v0.1.4.tar.gz` 与 `.sha256`，GitHub 记录的附件摘要与本地一致。三个仓库在发布提交上打了 `v0.1.4` 标签并已推送。

发布镜像经 `reboot-lk.py` 进 LK 后刷入测试机 `boot_a`，loader 的 build-id 为 `c7bd8555`，与此前驻留的 `a1c40aed` 只差 `mkstandalone.py`，loader 代码相同。复位后约 24 s 枚举，默认镜像自动启动 iOS 并显示锁屏，上滑解锁后主屏组件正常，「设置」能打开；「钱包」打开后黑屏，与 `air0018-r2` 的现象一致。
