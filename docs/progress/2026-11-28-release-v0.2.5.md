# v0.2.5 发布记录（2026-11-28）

## 1. 范围

本版继续使用 iOS 26.6.2（`23G90`，iPhone 17 `V57AP` 身份）与 XNU 12377 内核，从四个仓库对应 `v0.2.5` 提交基线发布：顶层 `91d409c8`、内核 `7ee0e4f8`、用户态 `426d6020`、`TrollStore` `5a84ac25`。同日完成批 1 起三仓历史提交信息规范整理并刷新 `v0.2.3`／`v0.2.4` 标签，相对 `v0.2.4` 的主要变化：

- 图形与桌面应用：补齐 `-constantDataAtIndex:`、完整渲染反射、稀疏参数槽位、`unused`/`nullable` 裁剪、持久 NIR 缓存 v3（`annibale-nircache-v3`）与 `is_frag_depth_store_deref()`，恢复天气城市卡片 VFX、详情页全屏夜空渐变与 10 日预报温标条；合入 Freedreno `128 MiB / 3 s` 复用、`AnnibaleGPU` `256 MiB` 保留池与免拷贝缓冲零拷贝复用路径消除稳态 `0xf1` 开销，详情页滚动提升至 `97–109 fps`；恢复主屏「相机」图标，实机验收可清除 `MTLTexture` 与地图四模式视图缩略图，见[批 25 记录](2026-11-28-batch25-results.md)、[批 27 阶段记录](2026-11-28-batch27-weather-air-bo-cache.md)与[批 28 记录](2026-11-28-batch28-results.md)。
- 相机与音频：合入 `OVX8000` `VC1` 相位差采集、`GT24P128F` EEPROM 校准解析与 `RAW10` 左右相位差闭环对焦（真机零 CDAF 回退），配合三槽连拍缓冲与曝光平滑；修复媒体音量按键作用域、低音量步进一致性并接入 `VirtualAudioDevice_Actuator` `duid` 对象解析（HAL 对象 ID `51`，余 `hapticd` XPC 超时），见[批 22 记录](2026-11-28-batch22-results.md)、[批 20 记录](2026-11-28-batch20-results.md)与[批 28 记录](2026-11-28-batch28-results.md)。
- 视频、网络、存储与内核：合入 Iris `P010` 位深协商与 `MiniIOMobileFramebuffer` `'420v'`/`'420f'` 双平面 YUV 缩放及多层预乘 `srcOver` 合成，真机验证 Safari 网页带音频彩色视频完整播放；打通 `PSCI OSI` 深睡与次核簇 `cluster1` 调频；补齐 `TimeAtHighSoc` 4 字节 `OSData` 与 `VacVoltageLimit = 4400 mV` 消除 `batteryintelligenced` 长期运行崩溃；修复 `kev_post_msg` 集群分配、`bcopy_phys_internal` 抢占中转、Wi-Fi 主动断开自动重连、可写 APFS 5 路径 `fsid` 往返及 ADSP `INIT_ATTACH(root)` 延迟续发队列，见[批 23 记录](2026-11-28-batch23-results.md)、[批 24 记录](2026-11-28-batch24-results.md)与[批 28 记录](2026-11-28-batch28-results.md)。

用户侧升级边界：分区、系统盘与数据盘结构不变。从 `v0.2.3` 或 `v0.2.4` 升级保留全部固件与 `fw/wifi-mac.txt`，只需按[体验说明 §6、§11](../user-guide.md#6-合成引导镜像)重新合成并刷入 `boot-ios.img`；从 `v0.2.0`～`v0.2.2` 升级补采 `fw/wifi-mac.txt` 后重合成刷机；`v0.1.2`～`v0.1.4` 须先按 `v0.2.0` 与[双系统部署手册](../plan/dual-boot-setup.md)迁移 APFS 数据盘。

## 2. 构建与发布校验

发布包按 [Release 执行清单](../plan/release-checklist.md) 在独立新克隆 `../hackios-release-v0.2.5` 中全量构建。

- 内核与用时：`build-all.sh` 8 阶段全通（`ios` 13 s、`userland` 9 s、`mesa` 88 s、`package` 8 s、`kernel` 238 s、`loader` 3 s、`android` 0 s、`apfstool` 272 s）；`xnu12377-local.bin`（`21,111,160` B，`03eb157a...`）与真机验证 `xnu12377-b28r3.bin`（`481ff89a...`）总长、`otool -l` 段布局及全量 `91,765` 排序符号名完全一致，差异仅在并行链接的段内符号排放顺序；内核版本字符串通过 `KERNEL_BUILDER` 固定为 `builder:xnu12377`。
- loader 与引导镜像：`avbtool.py info_image` 验证 `boot-a-ios.img`（`100,663,296` B / 96 MiB）含 AVB 页脚（`Original image size: 24635392 bytes`、`VBMeta offset: 24637440`、`512` B、Hash descriptor SHA-256 `789ff1a6...`）；`xnuloader build-id` 为 `af7b884730f8dddd257ab4473203778f8537d3da`。
- `apfs-tool`：三端二进制 SHA-256 与 `v0.2.4` 一致；`apfs-tool-Darwin` 含 `x86_64 arm64`、`minos 13.0`、仅依赖 `/usr/lib/libz.1.dylib` 与 `/usr/lib/libSystem.B.dylib`；Linux 两版为静态链接 ELF64。本机运行 `test_annfs.py --rounds 2 --objects 3000` 通过（`round 0..1 ok`）。
- 发布包清单：`build-release.py v0.2.5` 核对 `files_count: 160`、`local files by kind`: `plist: 558, copy: 13, skeleton: 1, firmware: 13, cache: 1`、`property list edits carry 77890 bytes of values`；`manifest.json` 记录 `91d409c87dc2ed31f61d6fcce816d01ff5a4b1c0` / `7ee0e4f8c69765d6c34248f9f3fb3e9732e31210` / `426d60204d7153c80b43cac94c1b146e0a439cd6` / `5a84ac250f8c7261bc2f49f42ebd01d19ec84132`，全包零本机目录与隐私残留。
