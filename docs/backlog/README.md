## 3. 状态与维护

- 「进行中」：已有执行批次，接续前确认当前分工。
- 「实现完成、待验证」：代码或宿主检查已有结果，仍需完成条目所列验收。
- 「待研究／未实现」：还有契约、依赖或实现工作。
- 「候选／条件项」：先确认当前需求、是否复现或前置条件；需要用户选择的具体取舍写在条目中。
- 新的未完成事项按主题写入本目录，来源文档记录分析与结果并链接到对应主题；同一事项只在一张表展开。
- 选定任务后，复杂批次可在 `docs/plan/` 记录执行安排，并从这里链接过去。完成后移除对应待办，结果写入专题，重要进展更新进度表。
- 每次维护核对较新的源码与实测。旧镜像的缺失、旧审批和已完成步骤只保留必要结果与出处。
