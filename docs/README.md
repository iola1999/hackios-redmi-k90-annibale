## 3. 文档放置

| 目录 | 用途 |
|---|---|
| `backlog/` | 未完成事项、候选方向和验收条件 |
| `plan/` | 已选批次的执行安排、架构决策和常设操作手册 |
| `analysis/` | 原理、根因、调研与实测数据 |
| `progress/` | 一轮一事的结果与专题链接 |
| `backup/` | 备份范围与恢复说明 |

原始日志、截图、转储和构建产物按现有忽略规则留在本地。公开文档保留必要摘录与来源链接。
